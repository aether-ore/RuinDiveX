# RuinDiveX Three.js Semantic Room Pack V1

This pack contains four authored, textured GLB room modules built for the current RuinDiveX industrial dungeon direction. Each file is Y-up, measured in metres, centered horizontally, and keeps the entry traversal tier at `Y = 0` even when playable geometry exists below it.

| GLB | Archetype | District | Gameplay purpose |
| --- | --- | --- | --- |
| `rdx_factory_corkscrew_exchange` | large_mini_dungeon_room | factory | A room-scale discrete corkscrew lift connects three exit heights while failed movement reveals a playable lower recovery floor. |
| `rdx_waterworks_freight_sump` | fluid_tank_chamber | factory, waterworks | A multi-region Waterworks room whose flooded, drained, and redirected states reveal different discoveries and exits. |
| `rdx_magma_foundry_undercroft` | hazard_processing_room | hazard_magma | An explorable lower foundry with a damage-free island route, a heat-resistance reward branch, enemies, and a permanent exit. |
| `rdx_electric_transformer_undercroft` | hazard_processing_room | hazard_electric | A cycling electrical sub-dungeon with a permanently safe insulated route, a timing-reward branch, grounding controls, and an upper shortcut. |

## Important integration rule

Do not use the current aggregate-bounds import rule (`model.position.y = -bounds.min.y`) for these modules. It raises lower Waterworks and Undercroft floors until the entrance socket no longer matches the generated room. Resolve `SOCKET_ENTRY_*`, place that node on the planned portal transform, and preserve the authored scale.

Likewise, do not project every visible mesh into an AABB obstacle. Read `collisionVolumes` from the corresponding JSON manifest. This avoids turning catwalk undersides, rails, pipes, water planes, overhead machinery, and hazard presentation meshes into invisible walls.

## Loading

```js
const gltf = await gltfLoader.loadAsync('/assets/models/rooms/rdx_factory_corkscrew_exchange.glb');
const room = gltf.scene;
const entrySocket = room.getObjectByName('SOCKET_ENTRY_SOUTH');
const consoleAnchor = room.getObjectByName('ANCHOR_MECHANISM_CONSOLE');
```

The GLBs contain embedded textures. The cropped PNG files are included separately for reuse by procedural connectors or matching props.

## Semantic prefixes

- `SOCKET_`: exact module connection marker.
- `REGION_`: encounter/minimap activation region marker.
- `WALK_`: authored traversal surface.
- `SHELL_`: room enclosure.
- `SUPPORT_` and `RAIL_`: visible structural support.
- `MECH_`: separately addressable mechanism node.
- `FLUID_`: water surface owned by environment state.
- `HAZARD_`: damaging presentation footprint owned by a hazard controller.
- `CONSOLE_`: visible interaction fixture.
- `ANCHOR_`: reward, encounter, safe-recovery, or interaction anchor.

## Source and provenance

Geometry was generated by `tools/generate_ruindivex_room_pack.py`. Embedded material maps were deterministically cropped from the RuinDiveX Factory, Waterworks, Magma Undercroft, and Electrical Undercroft tilesheets already present in the project workspace. No third-party meshes or textures are included.
