## Shared final prompt

The following prompt was used as the common production prompt, with the boss-specific identity block from the next table inserted at `BOSS IDENTITY`.

```text
Use case: stylized-concept
Asset type: landscape video-game boss design sheet and production design draft
Primary request: Design BOSS IDENTITY as a modular procedural Reaverbot boss. Make the advertised mechanical module the unmistakable, oversized gameplay silhouette and show how the boss uses it in combat.
Layout: one large three-quarter hero view; smaller clean front, side, and rear silhouettes; a featured-part close-up; a visibly energized phase-two state; one optional compatible supporting-part variation; and one small gameplay-distance thumbnail that proves the module remains readable from the player camera.
Visual direction: ancient ornate ceremonial machine geometry, restrained abstract ruin-glyph recesses, weathered olive-bronze armor, pale-gold structural trim, charcoal-black mechanisms, prominent ruby optics, and large functional moving parts. The ornament must reinforce attack function instead of hiding it. Nonhumanoid robotic anatomy only.
Rendering: polished game-production concept art, neutral dark warm-gray sheet background, coherent scale and materials across every view, crisp hard-surface construction, readable value grouping, restrained weathering, no UI framing.
Constraints: no words, no letters, no numbers, no captions, no logos, no watermark, no readable pseudo-writing, no humanoid face or anatomy, no decorative clutter over attack apertures, no tiny indistinct featured part, no unrelated environment scene.
```
