# Ruin Crawler Unity Port

This Unity project is an in-progress port of the Three.js game in the parent
repository. Open it from the full repository checkout because its shared asset
package resolves `../../../assets`.

Setup, MCP configuration, current status, controls, tests, limitations, and the
migration roadmap are tracked in [`../../docs/UNITY_PORTING.md`](../../docs/UNITY_PORTING.md).
